# 标签导航

[English](../tab-navigation.md) | 简体中文 · [← 返回 README](../../../README.zh-CN.md)

---

vipper 把平铺窗口管理器的导航方式带进 Chrome：**组是一个轴，组内标签是另一个轴**——与 Hyprland 里切换 workspace 和窗口是同一套心智模型。

![二维导航示意](../assets/tabnav.zh.png)

## 按键映射

| 按键 | 作用 | 语义 |
|---|---|---|
| `Alt+H` / `Alt+L` | 上一个 / 下一个**标签组** | 相当于切换 workspace |
| `Alt+J` / `Alt+K` | **组内**左 / 右切换标签 | 相当于切换窗口 |

> 默认采用 vim 风格字母键：`H/L` 切组、`J/K` 组内移动。这套键位天然避开 Chrome 保留的历史导航键 `Alt+←/→`（扩展不可覆盖）。四个键均可在 `chrome://extensions/shortcuts` 自行改绑。

## 精确语义

- **组 = Chrome 原生标签组**，按标签栏从左到右的视觉顺序映射为上→下。
- **隐式组**：连续的一段未分组标签视为一个组；被真实组隔断的两段散标签属于不同隐式组——导航顺序永远与你看到的一致。
- **每组记忆**：切到某组时，激活该组上次活跃的标签。
- **随行折叠**：目标组展开，其他组自动折叠。
- **不环绕**：到顶/到底、到左/到右后再按键无效。
- **仅当前窗口**：只考虑当前 Chrome 窗口的标签，多窗口互不干扰。

## 补充说明

- 4 个按键通过 `chrome.commands` 预置，浏览器全局生效——不依赖页面焦点。
- 无论当前标签是否分组都能切组；当前组由活跃标签的位置推导。
